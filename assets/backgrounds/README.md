# 빈방 배경 에셋

`room_empty_base_v1.png`은 독립 소품을 올리기 위한 16:9 불투명 배경이다. 벽, 걸레받이, 나무 바닥, 부드러운 햇빛만 포함하며 침대·가구·창문·문·러그·장식·캐릭터·UI는 포함하지 않는다.

`room_with_bed_corner_v1.png`은 위 빈방을 편집해 왼쪽 위 코너에 침대만 자연스럽게 합성한 현재 게임용 배경이다. 방 구조·카메라·바닥과 벽의 원근·조명·색감은 그대로 유지하고 침대와 접지 그림자만 더했다.

## ChatGPT 이미지 생성 프롬프트

```markdown
# 목표
귀엽고 몽글몽글한 2.5D 어드벤처 게임용 **빈방 배경** 1장을 생성한다.

## 화면
- 16:9 가로 화면
- 높은 3/4 시점의 인형집 같은 방
- 크림색 벽, 따뜻한 원목 바닥, 둥근 나무 걸레받이
- 왼쪽 위에서 들어오는 부드럽고 따뜻한 빛
- 아기자기한 점토 인형/디오라마 질감, 부드러운 색과 그림자
- 중앙과 바닥에 소품을 배치할 넓은 빈 공간

## 반드시 제외
- 침대, 가구, 창문, 문, 러그, 조명기구, 액자, 식물, 장식품
- 캐릭터, 글자, 로고, UI
- 바닥에 붙박이로 그려진 상호작용 소품

## 출력
- 배경 전체가 프레임 안에 들어오게 하고 가장자리를 자르지 않는다.
- 불투명 배경 이미지 1장만 출력한다.
```
