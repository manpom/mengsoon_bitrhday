# 맹돌이·맹순이 캐릭터 에셋 v2

ChatGPT 이미지 생성 기능으로 만든 캐릭터 기준 시트와 런타임용 스프라이트입니다.

## 폴더

- `reference/`: 두 캐릭터의 기준 턴어라운드 시트
- `sprites/v2_parts/`: 2방향씩 생성한 10프레임 원본 시트
- `sprites/`: 조립된 8방향 × 10프레임 마스터 시트
- `runtime/<character>/walk/`: 방향별 10프레임 스트립과 개별 PNG
- `runtime/maengdol/bed/`: 침대와 분리된 수면 캐릭터 레이어

## 걷기 방향 순서

마스터 시트는 8행 × 10열입니다.

1. `s` — 정면
2. `se` — 정면 오른쪽 대각
3. `e` — 오른쪽
4. `ne` — 후면 오른쪽 대각
5. `n` — 후면
6. `nw` — 후면 왼쪽 대각
7. `w` — 왼쪽
8. `sw` — 정면 왼쪽 대각

각 방향은 `오른발 접촉 → 체중 수용 → 최저점 → 반대발 통과 → 왼발 전진 → 왼발 접촉 → 체중 수용 → 최저점 → 반대발 통과 → 오른발 전진`의 10프레임입니다.

- 런타임 개별 프레임: `320×426`
- 방향 스트립: `3200×426`
- 8방향 마스터: `3200×3408`
- 모든 개별 프레임에는 사방 32px 완전 투명 안전 여백이 있습니다.
- 생성기가 반복 루프 포즈를 11개 배치하는 경우, 투명 공백으로 캐릭터 경계를 검출해 마지막 중복 포즈를 제외하고 정확히 10프레임으로 조립합니다.

## 수면

- `maengdol_sleep_1..5.png`: 호흡 수면 루프
- 런타임 프레임은 `512×512`, 48px 안전 여백을 포함합니다.
- 침대·베개·이불은 포함하지 않으며 추후 독립 소품 레이어와 합성합니다.

## QA 메모

- 런타임 PNG는 알파 채널을 유지합니다.
- 모든 런타임 프레임과 스트립의 외곽에는 최소 32px 완전 투명 안전 여백이 있습니다.
- 마스터 시트의 모든 캐릭터는 캔버스 안에 들어오며 신체 잘림이 없습니다.
- 균등 좌표만 믿지 않고 각 행의 실제 알파 공백으로 프레임 경계를 검출해 분리합니다.
- 생성형 원본이므로 실제 적용 전 각 프레임의 피벗을 발 중앙 기준으로 미세 조정하는 것을 권장합니다.
- 맹순이 앞니는 중앙선 없는 통짜 형태를 기준으로 합니다.

## 재생성·분할

마스터 시트를 교체한 뒤 프로젝트 루트에서 다음을 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\slice_character_sheets.ps1
```

분할 후 다음 검증을 실행하면 파일 수, 크기, 알파 채널, 32px 안전 여백을 모두 확인합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify_character_assets.ps1
```
