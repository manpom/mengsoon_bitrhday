# ChatGPT 이미지 생성 프롬프트 기록

## 기준 모델 시트

- 몽글몽글한 2.5D 미니어처 판타지 게임용 독창적 맹꽁이 커플
- 맹돌이: 초록 피부, 파우더 블루 튜닉, 짙은 파란 반바지, 황갈색 크로스백
- 맹순이: 민트 피부, 더스티 핑크 원피스형 튜닉, 베리색 가방, 중앙선 없는 통짜 앞니
- 각 캐릭터 정면·정면 3/4·측면·후면 3/4·후면

## 걷기 시트 공통

- 생성 단위: 10열 × 2행, 방향 2개씩 총 20프레임
- 최종 구성: S, SE, E, NE, N, NW, W, SW의 8방향 × 10프레임
- 프레임: 오른발 접촉, 체중 수용, 최저점, 반대발 통과, 왼발 전진, 왼발 접촉, 체중 수용, 최저점, 반대발 통과, 오른발 전진
- 실제 알파 투명 배경, 그림자·격자·글자 없음
- 동일한 크기·중심·바닥선·카메라·조명
- 각 캐릭터 전체를 자기 셀 중앙 80% 영역 안에 배치하고 사방 최소 10% 투명 여백 확보
- 첫 열 왼쪽, 마지막 열 오른쪽, 모든 열 아래쪽에서 머리·손·발·가방이 경계에 닿지 않음

## 맹순이 수정

- 모든 프레임에서 임의로 추가된 머리 리본 제거
- 얼굴이 보이는 프레임의 앞니를 중앙선 없는 하나의 흰색 형태로 복원
- 특히 SW 방향 모든 얼굴에도 동일한 통짜 앞니 유지
- 프레임 수, 구도, 의상, 방향, 알파 배경과 안전 여백은 유지

## 맹돌이 수면·기상

- 5열 × 2행
- 첫 행: 5프레임 호흡 수면 루프
- 둘째 행: 눈뜨기부터 앉기까지 5프레임
- 가방 미착용
- 침대·베개·이불·바닥·배경을 제외한 캐릭터 전용 투명 레이어
- 기상 3번은 기존 입 선과 입 구멍을 모두 지운 뒤 작은 원형 하품 입 하나만 다시 생성
- 기상 3번을 별도 분할·확대해 두 번째 입 선이 없는지 확인
