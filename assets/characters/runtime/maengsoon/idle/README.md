# 맹순이 대기·호흡 에셋

- `maengsoon_idle_1.png` ~ `maengsoon_idle_4.png`: 게임 적용용 독립 프레임
- `maengsoon_idle_strip.png`: 네 프레임을 한눈에 확인하기 위한 미리보기
- 모든 프레임은 원본 크기를 유지한 `704×704` 투명 캔버스입니다.
- 캐릭터 중심과 발 기준선(`y=640`)을 통일했습니다.
- 최소 64px 이상의 투명 안전 여백을 두어 인접 컷 혼입과 렌더링 잘림을 방지합니다.

## 생성 프롬프트

> 기존 맹순이 캐릭터 디자인을 정확히 유지한 게임용 스프라이트 시트를 만들어 주세요.
>
> **레이아웃**
> - 정확히 2열 × 2행, 총 4프레임
> - 순서: 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래
> - 정면을 바라보는 제자리 대기/잔잔한 호흡 루프
> - 각 캐릭터는 자기 사분면 중앙 70% 안에 완전히 들어오게 배치
> - 사방 15% 이상의 투명 여백과 프레임 사이 넓은 투명 간격
>
> **캐릭터 고정 사항**
> - 민트빛 아기 맹꽁이 맹순이
> - 차분한 분홍색 원피스/튜닉과 베리핑크 크로스백
> - 모자와 리본 없음
> - 하나로 이어진 흰색 앞니, 가운데 경계선이나 홈 없음
> - 네 프레임 모두 동일한 체형, 얼굴, 의상, 가방, 카메라, 조명, 크기
>
> **금지**
> - 신체·눈·발·가방 잘림 금지
> - 옆 프레임 캐릭터 일부 혼입 금지
> - 글자, 번호, 격자선, 그림자, 배경, UI 금지
> - 완전한 투명 배경 PNG

다시 생성하거나 원본을 교체한 뒤에는 프로젝트 루트에서
`powershell -ExecutionPolicy Bypass -File scripts/build_maengsoon_idle.ps1`을 실행합니다.
